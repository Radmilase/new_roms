## Цель работы. Оптимизировать распределение контактных усилий между пальцами пятипалой роботизированной руки при захвате объекта в среде MuJoCo, обеспечить устойчивый захват.

## Задачи проекта
1. Изучить существующие подходы к захвату объектов пятипалой
роботизированной рукой
2. Настроить симуляционную среду MuJoCo с пятипалой роботизированной рукой
для задачи статического захвата
3. Задать способ распределения усилий между пальцами и определить метрики
качества захвата
4. Реализовать алгоритм автоматического подбора распределения усилий между
пальцами
5. Провести экспериментальное исследование и сравнительный анализ
результатов, включая оценку устойчивости


### Описание репозитория
В данном репозитории выполнено исследование захвата пятипалой руки Shadow Dexterous Hand в среде MuJoCo.
Основная задача проекта это исследовать и оптимизировать распределение контактных усилий между пальцами при захвате объекта, опираясь на: тактильные сенсоры, устойчивость удержания объекта во времени.
В репозитории содежраться XML-cwtys, базовый скрипт захвата, скрипт оптимизации захвата.

Объект случайно размечается над захватом, выполняется серия попыток захвата, для каждой вычисляются метрики качества, далее они агрегируются в итоговую оценку качества и параметры с лучшим результатом анализируются.

### Описание среды и модели

В качестве среды была выбрана из библиотеки Gymnasium Robotics от Farama Foundation - [Shadow Dexterous Hand](https://github.com/Farama-Foundation/Gymnasium-Robotics?tab=readme-ov-file). Это набор сред, в которых используется антропоморфная роботизированная рука с 24 степенями свободы, выполняющая задачи по манипулированию объектами, такими как куб, яйцо или ручка. Существуют вариации этих сред, которые также включают данные с 92 сенсорных датчиков в пространстве наблюдения.

В рамках проекта исходные XML-сцены были модифицированы и расширены: добавлены различные объекты для захвата, настроены сенсоры касания на кончиках пальцев и ладони, а также реализован собственный протокол проведения экспериментов по оценке качества и устойчивости захвата.

## Скрипты
### Базовый скрипт
Код  5 попыток захвата с простым управлением: открытие-закрытие-удержание. Считает метрики качества такие, как контакты руки и среды, устойчивость удержания, дрейф и скорость объекта, а также активность тактильных сенсоров пальцев.
Критерий успеха учитывает стабильность, отсутствие опоры на окружение и наличие реального захвата кончиками пальцев с участием большого пальца.




### Скрипт оптимизации
Оптмизация захвата кисти. 
Над раскрытой рукой находится объект, который под действием гравитации опускается вниз. Задача руки — корректно схватить объект и устойчиво удерживать его, опираясь на тактильные сенсоры пальцев, а не на геометрию окружения. Параметры автоматически подбираются с помощью метода случайного поиска.

Каждый захват состоит из трёх фаз: открытие, закрытие и удержание.
На фазе закрытия усилие задается на каждом пальце отдельно, при считывании тактильных сенсоро оно зависит от параметров управленияю.

Какие параметры мы оптимизируем
Каждому пальцу захвата задаётся свой вес усилия (wFF, wMF, wRF, wLF, wTH).
Управление происходит ща счет ветором параметров ТЕТТА 
ФОРМУЛА ТЕТТЫ

#### Оптимизация параметров
Для подбора параметров используется случайный поиск (random search):
1. Случайным образом выбирается набор параметров theta;
2. Этот набор проверяется на нескольких захватах с разными начальными положениями объекта;
3. Для каждого захвата считается итоговая оценка;
4. Оценки усредняются;
5. Если результат лучше предыдущего — параметры сохраняются.
